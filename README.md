# Tablero de plantillas · Oracle NetSuite · Grupo Estevez

Seguimiento del llenado, revisión y carga de las plantillas de migración a Oracle NetSuite.

- **Sitio publicado:** se sirve desde GitHub Pages con el archivo `index.html`.
- **Etapas que se siguen:** E1 Llenado · E2 Revisión · E3 Carga en el repositorio de Oracle.
  Sandbox y Productivo se incorporarán cuando el proyecto llegue a esas etapas.
- **Vistas:** *Resumen ejecutivo* (para dirección) y *Detalle* (operativo, con filtros y tabla completa).

## Cómo se actualiza

1. Se captura el avance en el archivo maestro de control (Excel, fuera de este repositorio).
2. En el tablero local se carga ese Excel y se usa **Guardar corte (HTML)**.
3. El corte descargado reemplaza a `index.html` y se sube al repositorio.

El archivo es autocontenido: no depende de servidor, base de datos ni del Excel para mostrarse.
